# Source Index

This index maps the source IDs used in corpus-techniques.md to the corresponding works, text languages, and technique cards. It is for attribution and location only. This repository does not include or host complete game scripts, images, or audio; technique cards retain only the short textual references and commentary needed for analysis.

Line numbers and segment names in a card belong to a specific text version and may differ in another version. A translation, transcript, or extracted text supports only the local observations explicitly bounded by the card; it cannot by itself establish the quality of the original-language writing or the complete game experience. Work names and related intellectual property belong to their respective rights holders.
