# 雨停以前

原创工具示例。入口前的说明不显示给玩家；本例不需要悬疑或宏大主题。

::scene START
## 一把倒着撑的伞

[CUE: 保留檐下雨声；无音频时保留下面的可读雨景。]

许宁把滴水的伞搁进桶里。

**阿禾：** 它今天又朝我倒水了。

**许宁：** 你可以考虑把有洞的一面放在下面。

**阿禾：** 那一面是我的头。

桶里的伞缓缓翻了个面。许宁把手里完好的伞递过去，又看了看阿禾还抓着的伞骨。

::choice OFFER
::option lend | 借她的伞，明天还。
::set borrowed = true
**阿禾：** 明天还你。

**许宁：** 明天最好不要也下雨。
::goto RETURN
::option repair | 先一起看看这根歪掉的伞骨。
::set repaired = true
**阿禾：** 给它一次解释的机会。

**许宁：** 好。由你替它发言。
::goto REPAIR
::endchoice

::scene REPAIR
## 檐下

阿禾按住伞骨，许宁试着拨动卡扣。伞面忽然弹起来，两个人一起往后躲，谁也没先松手。

**许宁：** 它的解释挺有力度。

她从口袋拿出一张便条垫在卡扣下。阿禾看见上面写着“周五别忘了拿书”。

::choice NOTE
::option ask | 问问是什么书。
::set knows_book = true
**许宁：** 园艺。因为我把仙人掌养得开始同情我了。

**阿禾：** 它跟你说的？

**许宁：** 它倒向了隔壁阳台。
::option wait | 替她把另一边伞骨稳住。
**阿禾：** 这一边好了。

**许宁：** 别放。让我享受两秒成功的感觉。
::endchoice

卡扣终于合上。许宁把折湿的便条塞回口袋。

::goto RETURN

::scene RETURN
## 门口

::if knows_book
**阿禾：** 周五拿书的时候，我跟你去。

**许宁：** 你要对仙人掌发表意见？

**阿禾：** 我想见见隔壁阳台。
::elif repaired
**阿禾：** 这根伞骨比刚才直。

**许宁：** 你夸得真谨慎。
::else
许宁把伞柄转到阿禾方便接住的方向。

**许宁：** 别忘在公交车上。

**阿禾：** 我会跟它聊一路，让它记住我。
::endif

::choice WALK
::option together | 等她锁好门，一起走到路口。
阿禾没有先下台阶。许宁锁了两次门，第二次只是确认。

走到檐边，她把肩膀往阿禾那边挪了一点。
::ending TOGETHER
::option ahead | 先走一步，回头挥手。
阿禾在雨里试着转了半圈。伞没有再倒水。

回头时，许宁还站在檐下。他向她挥挥手，这次空着的手没有抓住任何快散开的东西。
::ending AHEAD
::endchoice
